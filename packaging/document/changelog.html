0.1.0

Current library functionality

  • C API headers for core utilities, rasterization graphics, fonts, images, animation, input, scenes, audio, platform windows, and CDSL.
  • A flat C++17 nector.hpp entry point with move-only RAII resource wrappers, typed enums, and nector::Error exception reporting.
  • RGBA surfaces, paths, painter state, clipping and transforms, solid colors, linear and radial gradients, stroking, masks, and surface composition.
  • TTF, TTC, OTF, OTC, WOFF, and WOFF2 font loading from files or memory, collection face selection, font and text metrics, text drawing, and glyph paths.
  • PNG, JPEG, BMP, and SVG image loading, RGBA image creation and pixel access, drawing, and PNG or BMP output.
  • Keyframe and 1–60 frame animation with easing, looping, Behaviour spans, Flipbook images, and synchronized Hybrid transforms. NKeystroke provides 0/1/2 key states with a 500 ms hold threshold.
  • Scene nodes and properties, UI callbacks, layout, drawing, animation binding, scrollable NInterface::Row controls, and lightweight glass NInterface::Button rendering.
  • Audio loading from files or memory with playback, volume, looping, seeking, and duration controls.
  • Application and window creation, event processing, rendering, and platform identification.
  • Text UI compilation into Data/Text/End .dll-nector data packages, package loading, scene access, action invocation, and event callbacks.

Tools and resources

  • nectorc compiles a .nector source file to a data package.
  • ndvwr displays a compiled package or validates it with --check.
  • nddbg statically inspects compiled packages with default objdump-style hexadecimal output, -d DSL decompilation, -s node/action symbols, and -t hexadecimal structure ranges. It does not create a window or execute actions.
  • The distribution includes public headers, monolithic and modular libraries, link or import libraries, locale catalogs, redistributable fonts, environment scripts, and license notices.

Release package additions

  • Added this English API overview, quick start, DSL guide, font guide, packaging guide, and changelog.
  • Added CMake package integration with Nector::nector, Nector::nector_dsl_compile, and modular Nector::nector_<module> targets.
  • Added nector.pc for pkg-config discovery.
  • Added release manifest and checksum metadata, plus library/build-info.txt for build-specific release information.

This page records only the current 0.1.0 functionality and this release update; it does not describe earlier releases.
