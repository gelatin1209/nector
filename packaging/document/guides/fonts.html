Load a file with nectorLoadFont(path, face_index, &font) or nector::Font(path, face_index). For bytes already in memory, use nectorLoadFontMemory or Font::fromMemory. nectorFontGetFaceCount and Font::faceCount inspect in-memory collection data before selecting a face.

#include <nector.hpp>

int main() {
    nector::Font font("library/assets/deja_vu_sans.ttf", 0);
    const auto font_metrics = font.metrics(24.0F);
    const auto text_metrics = font.measureText(24.0F, "Hello, Nector");
    return text_metrics.glyph_count > 0 && font_metrics.line_height > 0 ? 0 : 1;
}

Package assets and PATH

Redistributable fonts are files in library/assets; they are not executables. The environment scripts deliberately do not add library/assets to PATH. Setting PATH is for shared libraries and tools, not font discovery.

The library itself loads the path or memory supplied by the application. The bundled ndvwr tool uses this order:

  1. An explicit font-file command-line argument, when supplied.
  2. The path in NECTOR_FONT, when nonempty.
  3. deja_vu_sans.ttf in library/assets, located relative to the tool executable.

This relative fallback keeps the package relocatable. Applications using the API directly should pass their own font path and select a face index where needed.

Default and CJK environment variables

Both metadata/nctorvars.cmd and metadata/nctorvars.sh initialize these variables:

VariablePackaged file
NECTOR_FONTlibrary/assets/deja_vu_sans.ttf, the default for the bundled tools
NECTOR_FONT_SOURCE_HAN_SERIFlibrary/assets/source_han_serif_sc.otf
NECTOR_FONT_SOURCE_HAN_SANSlibrary/assets/source_han_sans_sc.otf
NECTOR_FONT_NOTO_SANS_CJKlibrary/assets/noto_sans_cjk_sc.otf

After loading the Windows environment, select Noto Sans CJK for the tools with:

set "NECTOR_FONT=%NECTOR_FONT_NOTO_SANS_CJK%"
ndvwr my-ui.dll-nector

After sourcing the shell environment on Linux or macOS, select Source Han Sans with:

export NECTOR_FONT="$NECTOR_FONT_SOURCE_HAN_SANS"
ndvwr my-ui.dll-nector

Alternatively, pass the selected font file as the optional tool argument. Font and third-party license notices remain in license.
