Quick start

Configure a Nector 0.1.0 package, build a C++17 application, and run the bundled tools.

1. Load the package environment

Commands on this page start at the extracted package root. Use binaries built for the current operating system and architecture.

Windows Command Prompt

call metadata\nctorvars.cmd

The script adds library to PATH, allowing Windows to find the DLLs and tools in the same directory.

Linux and macOS

. metadata/nctorvars.sh

Source the script rather than executing it in a child process. It adds the tools to PATH and configures LD_LIBRARY_PATH on Linux or DYLD_LIBRARY_PATH on macOS.

Both scripts define NECTOR_HOME, NECTOR_INCLUDE, NECTOR_STATIC, NECTOR_TOOLS, NECTOR_ASSETS, NECTOR_CONFIG, NECTOR_LOCALE, NECTOR_FONT, Nector_DIR, and PKG_CONFIG_PATH. The assets directory itself is not added to PATH.

2. Run the bundled tools

Compile a text UI description, validate its container, inspect its static records, and open the resulting data package:

nectorc my-ui.nector my-ui.dll-nector
ndvwr --check my-ui.dll-nector
nddbg -d my-ui.dll-nector > decompiled.nector
nddbg -s -t my-ui.dll-nector
nddbg --all my-ui.dll-nector
ndvwr my-ui.dll-nector
ndvwr my-ui.dll-nector path/to/font.otf

nectorc requires exactly an input and output path. ndvwr --check validates a package without creating a window; normal ndvwr accepts one package path and an optional font path. nddbg includes a hexadecimal dump by default, decompiles DSL with -d, lists symbols with -s, and reports hexadecimal structure ranges with -t. Addresses are file offsets and range ends are exclusive. Inspection does not load a scene or execute actions. An explicit viewer font argument takes precedence over NECTOR_FONT.

A .dll-nector file is a Nector Data/Text/End data package, not an operating-system DLL or VM bytecode. See the DSL guide for source syntax and runtime loading.

3. Build with CMake

Use the packaged CMake configuration and imported targets. If CMake does not find the package automatically, set Nector_DIR to the directory that contains NectorConfig.cmake.

cmake_minimum_required(VERSION 3.20)
project(MyNectorApp LANGUAGES CXX)

find_package(Nector CONFIG REQUIRED)
add_executable(my_app main.cpp)
target_compile_features(my_app PRIVATE cxx_std_17)
target_link_libraries(my_app PRIVATE Nector::nector Nector::nector_dsl_compile)

Link only Nector::nector if the application does not use DSL. Configure and build with:

After loading the environment, pass the configured package directory explicitly:

rem Windows Command Prompt
cmake -S . -B build -DNector_DIR="%Nector_DIR%"
cmake --build build

# Linux and macOS
cmake -S . -B build -DNector_DIR="$Nector_DIR"
cmake --build build

The equivalent main.cpp below loads the compiled package and invokes its finish action:

#include <nector.hpp>

int main() {
    auto package = nector::CdslPackage::load("my-ui.dll-nector");
    if (package.hasAction("finish")) {
        package.call("finish");
    }
}

Load nctorvars before running the application, or otherwise arrange the platform's shared-library search path. The packaging guide lists monolithic and modular CMake targets.

4. Build with pkg-config

The environment scripts add library/pkgconfig to PKG_CONFIG_PATH. After loading the environment on Linux or macOS:

pkg-config --cflags --libs nector
c++ -std=c++17 main.cpp $(pkg-config --cflags --libs nector) -o my_app

Use the resulting flags rather than manually guessing library search paths and transitive linker options. Runtime shared-library discovery remains a separate step.

5. Use timelines and interface controls

The complete C++ entry point exposes frame animation, deterministic key states, and interface controls. Frame counts are limited to 1–60. Behaviour frame ranges are inclusive, and a Hybrid samples its transform and image from the same timeline.

#include <nector.hpp>

NImation animation(60);
animation.addBehaviour(NImation::Behaviour::Forward, 0, 29, 0.0, 120.0);
animation.addBehaviour(NImation::Behaviour::TurnRight, 30, 59, 0.0, 90.0);
animation.start();
animation.tick(1000.0 / 60.0);
const auto transform = animation.sampleTransform();

nector::Scene scene("Controls", 640, 480);
NInterface interface(scene);
NInterface::Row row(interface, "items");
row.layout = 1; // vertical; 0 is horizontal
NInterface::Button button(interface, row, "accept", "Accept");
button.glass = true;
interface.layout(640, 480);

Use NImation::Flipbook flipbook(21) for image-only playback and NImation::Hybrid hybrid(21) when each frame also needs movement or rotation. NKeystroke::state(NKeystroke::signal::A) returns 0 for released, 1 for held up to 500 ms, and 2 only after more than 500 ms.
