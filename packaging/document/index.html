Quick start on Windows

Run these commands from the package root. The environment script adds both the DLL directory and nectorc to PATH.

call metadata\nctorvars.cmd
nectorc your-ui.nector your-ui.dll-nector
ndvwr --check your-ui.dll-nector
nddbg your-ui.dll-nector
nddbg -d your-ui.dll-nector > decompiled.nector
nddbg -s -t your-ui.dll-nector
ndvwr your-ui.dll-nector

The viewer uses NECTOR_FONT or locates deja_vu_sans.ttf in library/assets relative to its executable in library. No fixed installation directory is required, and the assets directory is not added to PATH.

Quick start on Linux and macOS

. metadata/nctorvars.sh
nectorc your-ui.nector your-ui.dll-nector
ndvwr --check your-ui.dll-nector
nddbg your-ui.dll-nector
nddbg -d your-ui.dll-nector > decompiled.nector
nddbg -s -t your-ui.dll-nector
ndvwr your-ui.dll-nector

The shell script configures LD_LIBRARY_PATH on Linux or DYLD_LIBRARY_PATH on macOS. Only binaries built for the current platform can be used.

Include and link

The single public C++ entry point is nector.hpp. Nector is not header-only; link the implementation libraries and keep the shared libraries discoverable at runtime.

#include <nector.hpp>

auto package = nector::CdslPackage::load("your-ui.dll-nector");
package.call("finish");

Windows/GCC example, after loading nctorvars.cmd:

g++ -std=c++17 main.cpp -Ilibrary/include library/static/Nector.dll.a library/static/Nector.DslCompile.dll.a -o app.exe

Linux/macOS shared-library example:

c++ -std=c++17 main.cpp -Ilibrary/include -Llibrary -lNector -lNector.DslCompile -o app

A .dll-nector file is a Nector data package with Data, Text, and End sections. It is not an operating-system dynamic library or VM bytecode.

Metadata and localization

FilePurpose
metadata/nector.jsonPlatform-independent relative directory map and default resources.
metadata/nector.*.jsonPlatform library naming and environment settings.
metadata/version.txtPackage, ABI, and layout versions.

Environment variables include NECTOR_HOME, NECTOR_INCLUDE, NECTOR_STATIC, NECTOR_TOOLS, NECTOR_ASSETS, NECTOR_CONFIG, NECTOR_LOCALE, NECTOR_FONT, Nector_DIR, and PKG_CONFIG_PATH. Additional CJK font selections are NECTOR_FONT_SOURCE_HAN_SERIF, NECTOR_FONT_SOURCE_HAN_SANS, and NECTOR_FONT_NOTO_SANS_CJK.
